# 哪吒监控 (Nezha Agent) Magisk 模块

> 💡 本模块旨在将 [哪吒监控客户端（nezha-agent）](https://github.com/nezhahq/agent) 通过 Magisk 模块的形式集成进 Android 系统，实现后台持续运行。
> 
> ⚠️ **架构提示**：模块自动构建的 `nezha-agent` 为 **ARM64 架构**，仅支持 64 位设备。

## ✨ 核心特性

*   🔄 **自动同步**：依托 GitHub Actions，定期拉取官方最新版核心进行打包。
*   ⚡ **基础守护**：内置守护脚本，包含断网等待、异常重试及防休眠机制。

## ✅ 使用方法

1. 前往本仓库的 **[Releases 页面]** 下载最新版本的压缩包（例如 `magisk-nezha-agent-vX.X.X.zip`）；
2. 解压压缩包，修改 `/bin/config.yml` 配置文件，填入您的面板通信地址、密钥等探针信息；
3. 将修改后的文件重新打包为 ZIP（注意保持原有目录结构）；
4. 通过 Magisk / KernelSU / APatch 等工具刷入该模块；
5. 重启设备，探针将在后台自动运行。

> 💡 **提示**：探针核心自身带有自动更新机制。

## 🔧 守护脚本 (`service.sh`) 逻辑说明

模块包含基础的后台运行与守护逻辑，主要工作机制如下：

*   **证书权限与通信**：设置环境变量 `SSL_CERT_FILE` 并使用内置 `bin/ca.crt` 根证书，维持 HTTPS 通信正常。
*   **网络与休眠控制**：启动前通过 Ping 检测网络状态；调用 `wake_lock` 防止设备休眠导致进程被终止。
*   **重试限制机制**：程序异常退出后会自动尝试重启。若连续失败超过 5 次，脚本将暂停 10 分钟后再试，防止异常情况下持续消耗设备电量和系统资源。

```text
