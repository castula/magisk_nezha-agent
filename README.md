# 哪吒监控 (Nezha Agent) Magisk 模块

> 💡 本模块旨在将 [哪吒监控客户端（nezha-agent）](https://github.com/nezhahq/agent) 通过 Magisk 模块的形式集成进 Android 系统，实现后台持续运行。本仓库的所有代码与文档均在 Gemini 的辅助下完成。
> 
> ⚠️ **架构提示**：模块自动构建的 `nezha-agent` 为 **ARM64 架构**，仅支持 64 位设备。

## ✨ 核心特性

*   🔄 **自动同步**：依托 GitHub Actions，定期拉取官方最新版核心进行打包。
*   ⚡ **基础守护**：内置守护脚本，包含容错网络检测、异常重试机制，并提供可自定义的电源管理模式。

## ✅ 使用方法

1. 前往本仓库的 **[Releases 页面]** 下载最新版本的压缩包（例如 `magisk-nezha-agent-vX.X.X.zip`）；
2. 解压压缩包，修改 `/bin/config.yml` 配置文件，填入您的面板通信地址、密钥等探针信息；
3. （可选）编辑 `service.sh` 文件，根据设备用途配置 `RUN_MODE` 变量以选择适合的休眠策略；
4. 将修改后的所有文件重新打包为 ZIP（注意保持原有目录结构）；
5. 通过 Magisk / KernelSU / APatch 等工具刷入该模块；
6. 重启设备，探针将在后台自动运行。

> 💡 **提示**：探针核心自身带有自动更新机制，config.yaml里未关闭自动更新的情况下，仅首次刷入一次即可。

## 🔧 守护脚本 (`service.sh`) 逻辑说明

模块包含基础的后台运行与守护逻辑，主要工作机制如下：

*   **运行模式（电源策略）**：脚本内置 `RUN_MODE` 变量，支持两种休眠控制方案：
    *   **方案 A (RUN_MODE=1)**：调用 `wake_lock` 唤醒锁，阻止 CPU 进入深度休眠，确保探针 24 小时强制在线。**注意**：会增加待机耗电，建议需要监控 24 小时运行的设备使用。
    *   **方案 B (RUN_MODE=2，默认推荐)**：通过读取底层背光节点（辅以 `dumpsys` 兜底）实时感知屏幕状态。手机息屏时向探针发送 `SIGSTOP` 信号将进程挂起冻结（彻底切断后台轮询与网络发包），亮屏唤醒时发送 `SIGCONT` 信号瞬间恢复运行。**特点**：实现息屏零 CPU 占用与零网络唤醒，彻底释放系统深度休眠，对电池续航几乎无影响，适合日常主力机。
*   **轻量网络检测**：探针首次启动或异常重连前会进行单次快速 Ping 检测（`223.5.5.5`）确认网络连通性；在方案 B 息屏冻结期间完全跳过网络检测，避免因后台发包唤醒无线基带。
*   **进程守护与自愈机制**：脚本启动时自动清理残留进程防止冲突，运行期间持续监控进程状态。若探针发生意外崩溃退出，会在网络恢复或亮屏状态下自动重新拉起（无网络时自动休眠等待，防止死循环空转消耗系统资源）。
*   **证书权限与通信**：设置环境变量 `SSL_CERT_FILE` 并使用内置 `bin/ca.crt` 根证书，维持 HTTPS 通信正常。
